# Copilot Tips

This document provides best practices for using GitHub Copilot effectively in the VetClinic Manager project.

## Prompting Best Practices

- Be specific: Instead of "add a button", say "add a blue submit button with 'Save' text"
- Provide context: Include file paths or @workspace references
- Use natural language: Write prompts as you would explain to a colleague
- Iterate: Refine prompts based on initial responses

## Collaboration Tips

- Review Copilot suggestions carefully
- Use Copilot for repetitive tasks like boilerplate code
- Combine with manual coding for complex logic
- Test generated code thoroughly

## Examples

- Good: "Create a React component for displaying animal cards in src/components/cards/AnimalCard.tsx"
- Bad: "Make a component"

## Keyboard Shortcuts

- `Tab` - Accept suggestion
- `Ctrl + Enter` - Open Copilot panel
- `Alt + ]` - Next suggestion
- `Alt + [` - Previous suggestion

## When to Use Copilot

- Generating boilerplate code
- Exploring API usage
- Writing tests
- Refactoring existing code

Avoid using Copilot for:
- Security-critical code without review
- Complex business logic without understanding
